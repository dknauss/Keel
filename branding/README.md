# Retired marks

These three files are the two-sail boat Keel used before 2026-08-09, kept for the
record. Nothing in the plugin or the wordpress.org listing uses them.

| File | What it was |
| --- | --- |
| `keel-mark.svg` | The square mark, in `currentColor`. |
| `keel-logo-horizontal.svg` | Mark and outlined wordmark, side by side. |
| `keel-logo-stacked.svg` | Mark above the outlined wordmark. |

The current mark is the racing yacht with one fin keel. Its source files, colours,
type, tagline and rules are in
[`.wordpress-org/brand/`](../.wordpress-org/brand/README.md), next to the listing
icons and banners made from them.
