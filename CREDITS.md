Keel is a de-branded evolution of **Better by Default**, the WordPress defaults
plugin by **WPYEG** (the Edmonton WordPress meetup):
<https://github.com/WPYEG/Better-by-Default>.

Better by Default is licensed GPL-3.0-or-later. Keel is a derivative work under the
same licence; original copyright is retained by its authors. Keel keeps Better by
Default's core architecture — a single schema array that drives both the settings
screen and the bootstrap, where each default is one array entry plus one hook — and
adds further hardening and admin defaults adapted from the Pixel Managed Platform
plugin (also GPL, GPL-2.0-or-later, which composes into GPL-3.0).
