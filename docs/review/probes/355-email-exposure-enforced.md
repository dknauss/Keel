Use disposable sites, synthetic `.test` addresses, and distinct accounts or restored snapshots for independent cases. Record exact runtime versions and database engines. Cover the WordPress 6.4 / PHP 7.4 floor, the declared tested WordPress 7.1 line on supported PHP, single-site and multisite, and both MySQL-family and SQLite labs. Exercise real HTTP entry points with independent sessions. Keep each trigger isolated so a later request cannot hide an earlier write.
